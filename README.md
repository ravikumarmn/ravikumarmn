- **[Enterprise GenAI copilot](https://ravikumarmn.github.io/work/agentic-rag-copilot)**: agentic RAG over documents, tables, and analytics tools, with hybrid retrieval and query planning. 1.8s end to end.
- **[Document intelligence](https://ravikumarmn.github.io/work/document-intelligence)**: Docling parsing and LLM extraction turn PDFs into JSON, a knowledge graph, and grounded answers, in under 3s per page.
- **[Model adaptation](https://ravikumarmn.github.io/work/model-adaptation)**: SFT with LoRA, contrastive embeddings, and transformer classifiers taken from 78% to 89% accuracy.
